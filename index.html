DATA INPUT

How information gets into Money Moves

  1. Current local workflow: select a local CSV file to import. The V2 import workflow is not part of this foundation release.
  2. Vault authority: this Mac’s encrypted vault file is the live source of truth. Manual encrypted backup is available from this screen.
  3. Not included: direct bank APIs, background synchronization, or cloud backup. Those require separate approved phases.

VAULT SECURITY

Encrypted vault

AES-256-GCM encryption, PBKDF2-SHA-256 key derivation, and a 60-minute inactivity lock. Your passphrase is never stored. Only you can decrypt your local vault and encrypted backups.

MONTHLY ROLLOVER

Automatic when opened

Money Moves checks your Mac’s local date at launch. When a new month begins, it selects the new month automatically, keeps your targets, rules, visited cities, and bucket order, and calculates actuals from transaction dates. It does not need to remain open at midnight.

A local website cannot fetch new transactions while closed. Import a fresh CSV when you want current activity.
