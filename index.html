DATA INPUT

How information gets into Money Moves

  1. Current seed: this build includes a snapshot from your connected Finances accounts through July 28, 2026.
  2. Current local workflow: this legacy UI can select a local CSV file; the V2 import workflow is not part of this foundation release.
  3. Not included: direct bank APIs or background synchronization. Those require a separate aggregator integration and secure token service.

VAULT SECURITY

Encrypted vault

AES-256-GCM encryption, PBKDF2-SHA-256 key derivation, and a 60-minute inactivity lock. Your passphrase is never stored anywhere, on this device or off it — only you can decrypt your data.

PREFERENCES

Monthly behavior

MONTHLY ROLLOVER

Automatic when opened

Money Moves checks your Mac’s local date at launch. When a new month begins, it selects the new month automatically, keeps your targets, rules, visited cities, and bucket order, and calculates actuals from transaction dates. It does not need to remain open at midnight.

A local website cannot fetch new transactions while closed. Import a fresh CSV when you want current activity.
